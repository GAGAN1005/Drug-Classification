# Drug Classification - ONNX Runtime Web Demo

This application provides real-time client-side drug classification using ONNX Runtime Web.
Trained via automated CI/CD with GitHub Actions & CML.

### Features
- **Client-side inference**: Models execute directly inside your browser via WebAssembly using `onnxruntime-web`.
- **Zero server costs**: Hosted on Hugging Face Static Spaces with no persistent Python backend needed.
- **Continuous Integration & Deployment**: GitHub Actions pipeline automates testing, training, reporting (CML), and publishing.
